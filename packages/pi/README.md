# @weldall/pi

Pi extension that loads administrator-managed WeldAll Markdown skills. Install with `pi install npm:@weldall/pi` (the npm `@weldall/cli` dependency is required), then restart Pi. Use `/weldall-refresh` to refresh skills; each skill appears as `/weldall-<skill-id>`.

The extension delegates authentication and API behavior entirely to the installed `weldall` CLI.
