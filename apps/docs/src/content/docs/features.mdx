## CLI appendix

The CLI appendix tells agents to use Weldall for company-specific tasks. Administrators briefly describe when Weldall is the right place to start.

The company Seibert Group (which makes Weldall) could, for example, add the following:

```text
$ weldall

Agents can discover approved capabilities and access APIs with scoped credentials.
Start with `weldall skills find <keywords>`, browse with `weldall skills list` when needed,
then use `weldall skills show <skill-id>` for instructions.

╔═ Organization instructions ═════════════════════════════════════════════╗
║ If the user wants to do something explicitly or implicitly related to   ║
║ the Seibert Group because it uses one of its systems, use Weldall.       ║
║ This includes Atlassian licenses, Personio, and HubSpot.                 ║
║ Start with weldall skills find using the task's nouns and actions.      ║
╚══════════════════════════════════════════════════════════════════════════╝

⋮
```
