## Our recommendation

We recommend the open-source agents **OpenWork and Pi** and use both with Weldall every day.

The Weldall CLI is not tied to a particular agent. The agent needs permission to run it as a command. Setup guides for OpenWork and Pi are in preparation.

## Other agents

[Claude Code](https://docs.anthropic.com/en/docs/claude-code), [OpenCode](https://opencode.ai), [Codex CLI](https://developers.openai.com/codex/), and [Gemini CLI](https://github.com/google-gemini/gemini-cli) can also invoke the Weldall CLI. The CLI must be installed in the agent's environment, and command execution must be allowed there.

The Weldall CLI runs on macOS, Windows, and Linux. Standalone binaries require no Node.js and are available for macOS on Apple Silicon and Intel, Windows x64, and Linux x64. See the [package overview](../sdks/) for installation.

## SDKs for your own web services

We provide TypeScript and Python libraries that validate incoming requests. The integration guides show how to add them to your application.

The TypeScript SDK requires Node.js 22.15 or newer; the Python SDK requires Python 3.11 or newer. Both libraries also work without the listed web frameworks.
