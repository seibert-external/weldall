A Weldall skill should generally be an **operational instruction for an agent**. It describes a specific task that the agent either:

1. performs through a protected company interface — a Weldall resource — or
2. when no interface exists, directs the employee to the browser or names a contact person.

If the second case is used frequently, it can be worthwhile to turn it into a Weldall resource.

A skill is not static knowledge, meaning company information that rarely changes. That information can live in external documentation, for example in Confluence or a static knowledge base such as Starlight.
