Die Weldall CLI ist nicht an einen bestimmten Agenten gebunden. Entscheidend ist, dass der Agent sie als Befehl ausführen darf. Anleitungen für die Einrichtung mit OpenWork und Pi sind in Vorbereitung.

## Weitere Agenten

Auch [Claude Code](https://docs.anthropic.com/en/docs/claude-code), [OpenCode](https://opencode.ai), [Codex CLI](https://developers.openai.com/codex/) und [Gemini CLI](https://github.com/google-gemini/gemini-cli) können die Weldall CLI aufrufen. Die CLI muss in der Umgebung des Agenten installiert sein; die Ausführung von Befehlen darf dort nicht gesperrt sein.

Die Weldall CLI läuft unter macOS, Windows und Linux. Binaries ohne Node.js-Abhängigkeit gibt es für macOS auf Apple Silicon und Intel sowie für Windows x64 und Linux x64. Die [Paketübersicht](../sdks/) beschreibt die Installation.
