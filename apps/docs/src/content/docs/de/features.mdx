## CLI-Appendix

Das CLI-Appendix weist Agenten darauf hin, Weldall für unternehmensspezifische Aufgaben zu verwenden. Administratoren beschreiben dort kurz, wann Weldall der richtige Einstieg ist.

Das Unternehmen Seibert Group (das Weldall herstellt) könnte zum Beispiel Folgendes hinterlegen:

```text
$ weldall

Agents can discover approved capabilities and access APIs with scoped credentials.
Start with `weldall skills find <keywords>`, browse with `weldall skills list` when needed,
then use `weldall skills show <skill-id>` for instructions.

╔═ Organization instructions ═════════════════════════════════════════════╗
║ Wenn der Nutzer etwas tun möchte, das explizit oder implizit mit der    ║
║ Seibert Group zusammenhängt, weil es eines ihrer Systeme nutzt,         ║
║ verwende Weldall. Dazu gehören Atlassian-Lizenzen, Personio und HubSpot. ║
║ Beginne mit weldall skills find und Begriffen aus der Aufgabe.          ║
╚══════════════════════════════════════════════════════════════════════════╝

⋮
```
