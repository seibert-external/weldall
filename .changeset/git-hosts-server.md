Add the app registry and the app host API for Git apps. A Git app is a separate service (`@weldall/git-app`) that keeps the repositories of people's apps on a Git host and is registered in Weldall as a resource; Weldall itself never talks to a Git host. A machine client with the new machine-only system scope `weldall:app-host` that is allowed for that resource registers apps for a person (`POST /api/app-host/v1/apps`), updates their links and repository (`PATCH /api/app-host/v1/apps/{id}`), resolves an app and its owner (`POST /api/app-host/v1/apps/lookup`) and reports the Git audit events of its apps (`POST /api/app-host/v1/audit-events`, idempotent per `eventId`, the person recorded as actor and the machine client as client), always limited to that resource's apps; announced as `weldall_app_host` in the OAuth metadata. The reported events are `git_repository.*`, `git_push.*`, `git_fetch.*`, `git_pull_request.*`, `git_credential.*` and `git_host.checked`, with strict metadata schemas; credentials in reported text are redacted before they are stored. Every registered app records name, owner, purpose, repository, template, links, creation, last confirmation and expiry (INV-183). Owners list their apps and confirm them every 90 days (`GET /api/me/apps`, `POST /api/me/apps/{id}/confirm`, audited as `app_confirmation.*`); publishing does not extend the expiry, and an expired app is only flagged, never stopped. Administrators see all apps under **App registry**, expired and expiring ones first. Machine clients with the new machine-only system scope `weldall:app-registry-read` read the registry from `GET /api/app-registry/v1/apps` (paginated, announced as `weldall_app_registry` in the OAuth metadata). A resource that registered apps cannot be deleted. `POST /api/authorization/v1/check-scopes` now also answers `weldall:login` for a machine client with at least one allowed resource, so a Git app can stop serving a person who may no longer use Weldall. The database migrations add the app registry and the new audit event types.
