Publish apps to GitHub for people without a GitHub account. A new `github-app` connector type (IaC discovery feature `git-hosts-v1`) holds a GitHub App's private key on a shared connection, uploaded in the admin UI. Weldall creates a private repository from a configured template, forwards git through its git proxy at `/git/<connector>/<owner>/<repository>.git` (only `weldall/publish-*` branches, never the default branch; 100 MB per push), opens a pull request that requests the reviewer team, and reports reviews, checks and preview and live links. New endpoints: `POST /api/me/apps`, `POST /api/me/git-credentials` (five-minute git credentials for one app's repository, never a GitHub token), `POST /api/me/apps/{id}/pull-requests`, `GET /api/me/apps/{id}/status`, and the administrator check `GET /api/admin/connectors/{key}/check`. Repository creation, every push and fetch, pull requests, git credentials and connector checks are audited (`git_repository.*`, `git_push.*`, `git_fetch.*`, `git_pull_request.*`, `git_credential.*`, `git_host.checked`). The database migrations add the app registry, the new audit events and git credentials. GitHub App connectors are server-only: they do not appear in connector or connection listings, so existing CLIs are unaffected.
